# Contributing

Volunteer contributions are welcome. Describe the operational problem, add a regression test, and open a pull request. Run `python -m unittest discover -s tests -v` and `python -m offshore.demo` before submitting.

Keep source code free of inline comments. Explain constraints and decisions in documentation. Use direct English in documentation and commit messages. Never upload real crew records, credentials or production databases.

Only claim authorship or co-authorship for work actually contributed. Assistant-assisted submissions should state how the work was produced. Merging from a second account does not establish independent review.
