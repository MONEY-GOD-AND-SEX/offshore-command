# Delivery status

The original package is restored in the repository. The Python/SQLite engine, allocation planner, regression tests, Codespaces workspace and static training dashboard are included.

The `Verify operations` workflow tests Python 3.12 and 3.13 and produces execution evidence. The `Deploy operations workspace` workflow runs tests, generates a synthetic engine snapshot and publishes GitHub Pages after a push to main.

The website is a browser training sandbox. Durable crew operations remain in SQLite through the CLI. No real crew information is published and GitHub is not represented as a managed application database.

Submissions use the authorized primary and secondary account connections. The commit history records the actual submitting accounts. No independent review is claimed.
